# Kukusanku - Website Jualan Kukusan

Website toko online untuk usaha jualan kukusan.

## Cara Pakai

1. Buka file `index.html` di browser (double-click atau drag ke Chrome/Firefox).
2. Untuk admin, buka `admin.html`.

### Login Admin
- Username: `admin`
- Password: `kukusanku123`

### Fitur
- **Pembeli**: Lihat produk, masukkan keranjang, pesan via WhatsApp, daftar/login, share lokasi.
- **Admin**: Tambah/edit/hapus produk, ubah harga & stok, lihat pesanan masuk.

### Catatan Penting
- Data disimpan di localStorage browser (masih demo).
- Ganti nomor WhatsApp di `script.js` (cari `waNumber`).
- Untuk dipakai online, upload semua file ke hosting gratis seperti Netlify / Vercel / GitHub Pages.

## File
- `index.html` → Halaman utama
- `admin.html` → Panel admin
- `style.css` → Tampilan
- `script.js` → Logika website
